Nouveautés de WhatsReminder

Historique public des versions

Retrouvez ici les évolutions importantes de l’extension. Chaque version publiée est aussi accompagnée de notes détaillées dans le changelog technique.

  1. Version 1.0.6À venir

    Accédez aux nouveautés depuis l’extension

    • Le menu Paramètres affiche la version réellement installée.
    • Un lien direct permet d’ouvrir cette page pour consulter les nouveautés.
  2. Version 1.0.514 septembre 2026

    Un retour plus simple et une interface harmonisée

    • Envoyez votre avis via un formulaire Tally, en français ou en anglais.
    • Les fréquences personnalisées ont la même présentation dans l’extension et WhatsApp Web.
    • Consultez une page publique qui résume les nouveautés de chaque version.
  3. Version 1.0.413 septembre 2026

    Des rappels configurables

    • Choisissez l’heure du rappel quotidien et les priorités à inclure.
    • Les réglages de notifications sont directement accessibles depuis les paramètres.
    • Le guide interactif présente les notifications, sans les activer automatiquement.
  4. Version 1.0.311 septembre 2026

    Une interface plus compacte et un guide dans WhatsApp Web

    • La popup tient désormais dans la hauteur disponible : seuls les suivis défilent.
    • Ouvrez ou retrouvez WhatsApp Web depuis l’extension.
    • Un guide facultatif aide à créer le premier suivi directement dans WhatsApp Web.
    • Le menu rassemble tutoriel, langues et thèmes sans encombrer l’en-tête.
  5. Version 1.0.031 août 2026

    Première version stable

    • Créez des suivis locaux pour des conversations individuelles ou de groupe.
    • Visualisez les priorités, modifiez les fréquences, mettez un suivi en pause ou supprimez-le.
    • Recevez un rappel quotidien local et gardez vos données sur votre navigateur.

Les fonctionnalités à venir peuvent évoluer avant leur publication. Pour une correction ou un détail technique, consultez le changelog lié ci-dessus.
