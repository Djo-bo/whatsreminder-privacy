What's new in WhatsReminder

Public version history

Find the key improvements to the extension here. Every published version also has detailed notes in the technical changelog.

  1. Version 1.0.6Coming soon

    Access release notes from the extension

    • The Settings menu shows the version that is actually installed.
    • A direct link opens this page to view the latest changes.
  2. Version 1.0.5September 14, 2026

    Simpler feedback and a consistent interface

    • Send feedback through a Tally form, in French or English.
    • Custom frequencies use the same layout in the extension and WhatsApp Web.
    • A public page now summarizes the changes in each version.
  3. Version 1.0.4September 13, 2026

    Configurable reminders

    • Choose the time for the daily reminder and the priorities to include.
    • Notification settings are available directly from Settings.
    • The interactive guide introduces notifications without enabling them automatically.
  4. Version 1.0.3September 11, 2026

    A more compact interface and a guide in WhatsApp Web

    • The popup fits the available height: only tracking cards scroll.
    • Open or return to WhatsApp Web from the extension.
    • An optional guide helps create the first tracking item in WhatsApp Web.
    • The menu groups tutorial, language and theme controls without crowding the header.
  5. Version 1.0.0August 31, 2026

    First stable release

    • Create local tracking for individual and group conversations.
    • View priorities, change frequencies, pause or delete tracking.
    • Receive a local daily reminder while keeping your data in your browser.

Upcoming features may change before release. For fixes and technical detail, consult the changelog linked above.
